# Dataset

`creditcard.csv` is not stored here due to its large size (144MB).

## Download
1. Go to [Kaggle — Credit Card Fraud Detection]
   (https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
2. Download `creditcard.csv`
3. Place it in this `data/` folder
4. Run the notebook

## Info
- Rows    : 284,807 | Columns : 31
- Fraud   : 492 (0.17%) | Genuine: 284,315 (99.83%)
